# Schedule SmartUser 系统操作手册

## 1. 文档说明

本文档用于说明 Schedule SmartUser 系统的日常使用方式，适用于系统管理员、调度人员、数据导入人员和路线查看人员。

系统主要功能包括：

- 用户登录与退出。
- 用户、菜单、权限基础维护。
- CSV / Excel 巡检数据导入。
- 导入记录分页查询、清空查询、查看详情、编辑、取消、删除、批量删除、导出。
- Routes map 路线数据查看、分页查询、选择导出、全部导出、删除、批量删除。
- Routes map 页面内联编辑 `Inspector`、`Date`、`Time`、`Product`、`Note`，点击 `Save` 按钮持久化保存。
- Google Sheet 同步状态检查和导入后同步。

## 2. 访问地址

本地开发环境默认地址：

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| 前端 | `http://127.0.0.1:5173/login` | 用户登录入口 |
| 后端 | `http://127.0.0.1:8088` | REST API 服务 |
| 健康检查 | `http://127.0.0.1:8088/api/health/status` | 后端服务状态检查 |

## 3. 初始管理员

系统不再提供弱默认密码。首次创建或恢复管理员时，临时设置
`SCHEDULE_BOOTSTRAP_ADMIN_PASSWORD` 后启动后端。账号创建成功后立即删除该环境变量。
管理员用户名默认是 `admin`，密码必须使用新的强密码；数据库只保存 BCrypt 哈希。

## 4. 登录与退出

### 4.1 登录

1. 打开 `http://127.0.0.1:5173/login`。
2. 输入用户名和密码。
3. 点击 `Login`。
4. 登录成功后进入 `Dashboard` 页面。

登录成功后，系统会保存 token、当前用户、菜单和权限信息。后续接口请求会自动携带 token。

### 4.2 退出

1. 点击右上角 `Logout`。
2. 系统会调用后端退出接口，清理本地登录缓存。
3. 页面跳转回登录页。

## 5. 主界面说明

左侧菜单由后端菜单配置返回，默认包括：

| 菜单 | 路径 | 功能 |
| --- | --- | --- |
| Dashboard | `/dashboard` | 系统模块概览 |
| User Management | `/system/users` | 用户管理 |
| Menu Management | `/system/menus` | 菜单管理 |
| Permission Management | `/system/permissions` | 权限管理 |
| Inspection Import | `/inspections/import` | 巡检数据导入和导入记录维护 |
| Routes map | `/routes/map` | 路线数据查看和路线记录维护 |

## 6. 用户管理

路径：`User Management`

### 6.1 新增用户

1. 输入 `Username`、`Real name`。
2. 选择 `Role`：`admin`、`scheduler`、`viewer`。
3. 选择 `Status`：`Enabled` 或 `Disabled`。
4. 输入初始密码。
5. 点击 `Add user`。

### 6.2 编辑用户

1. 在用户列表中点击 `Edit`。
2. 修改真实姓名、角色或状态。
3. 如需重置密码，填写 `Password`；不填写则不修改密码。
4. 点击 `Update user`。

### 6.3 清空表单

点击 `Clear`，表单恢复新增状态。

## 7. 菜单管理

路径：`Menu Management`

菜单管理用于维护左侧导航菜单。

| 字段 | 说明 |
| --- | --- |
| Name | 菜单显示名称 |
| Path | 前端路由路径 |
| Component | 前端组件名称 |
| Permission | 访问该菜单需要的权限编码 |
| Sort order | 排序号，数字越小越靠前 |
| Visible | 是否显示 |

操作方式：

1. 填写菜单信息。
2. 点击 `Add menu` 新增菜单。
3. 点击列表中的 `Edit` 可编辑菜单。
4. 点击 `Clear` 清空表单。

## 8. 权限管理

路径：`Permission Management`

权限管理用于维护系统权限编码。

| 字段 | 说明 |
| --- | --- |
| Code | 权限编码，例如 `route:map` |
| Name | 权限名称 |
| Description | 权限说明 |

操作方式：

1. 填写权限编码、名称和说明。
2. 点击 `Add permission` 新增权限。
3. 点击列表中的 `Edit` 可编辑权限。
4. 点击 `Clear` 清空表单。

## 9. Inspection Import 数据导入

路径：`Inspection Import`

### 9.1 支持文件格式

系统支持导入：

- `.csv`
- `.xls`
- `.xlsx`

上传限制：

- 单文件最大 `20MB`。
- 请求最大 `20MB`。

### 9.2 导入步骤

1. 打开 `Inspection Import` 页面。
2. 点击 `选择文件`。
3. 选择 CSV / Excel 文件。
4. 点击 `Import file`。
5. 系统解析文件并写入 MySQL。
6. 导入成功后页面显示批次号、成功行数、失败行数和扫描行数。
7. 如已配置 Google Sheet，同步成功或失败信息会单独显示。

### 9.3 Google Sheet 状态检查

点击 `Check Google Sheet` 可检查后端 Google Sheet 同步配置和网络连通性。

状态说明：

| 状态 | 含义 |
| --- | --- |
| `success` | 同步配置有效，Google Sheet 可访问 |
| `skipped` | 同步被关闭或无数据需要同步 |
| `failed` | 同步配置缺失、网络失败或目标 Sheet 不可访问 |

## 10. Imported Inspection Records 列表

位于 `Inspection Import` 页面下半部分。

### 10.1 查询条件

| 查询条件 | 说明 |
| --- | --- |
| Start date | 巡检开始日期 |
| End date | 巡检结束日期 |
| Inspector | 检查员 |
| Sales | 销售 |
| Keyword | 支持按 MAC、电话、客户姓名、地址、Sales 模糊查询 |

点击 `Search` 执行查询。点击 `Clear` 清空查询条件并回到第一页。

### 10.2 分页

列表支持分页查询。

| 控件 | 说明 |
| --- | --- |
| Previous | 上一页 |
| Page | 输入页码并回车跳转 |
| Next | 下一页 |
| Page size | 每页条数，默认 `10`，可选 `10`、`20`、`50`、`100` |

### 10.3 查看详情

点击行内 `Detail`，可查看完整导入字段。

### 10.4 编辑记录

点击行内 `Edit`，弹出编辑窗口，可编辑导入记录字段。点击 `Save` 保存，点击 `Cancel` 关闭弹窗。

### 10.5 取消记录

点击行内 `Cancel`，系统会把该记录状态改为 `Cancelled`，数据不会被物理删除。

### 10.6 删除记录

点击行内 `Delete` 删除单条记录。该操作会物理删除数据库记录，执行前系统会弹出确认框。

### 10.7 批量删除

1. 勾选需要删除的记录。
2. 点击 `Delete selected`。
3. 确认后系统按勾选 ID 批量删除。

当勾选表头选择框并处于“全部选择”状态时，点击删除会按当前查询条件删除全部匹配数据。

### 10.8 导出

| 按钮 | 说明 |
| --- | --- |
| Export all | 按当前查询条件导出全部记录 |
| Export selected | 只导出当前勾选记录 |

导出文件格式为 CSV，包含 UTF-8 BOM，便于 Excel 直接打开。

## 11. Routes map 页面

路径：`Routes map`

### 11.1 筛选条件

| 条件 | 说明 |
| --- | --- |
| Start date | 起始日期 |
| End date | 结束日期 |
| Route | 路线，当前按 Inspector 聚合；未分配显示为 `Unassigned` |

点击 `Update map` 重新加载路线数据。点击 `Clear` 清空筛选条件。

### 11.2 统计卡片

页面顶部展示：

| 指标 | 说明 |
| --- | --- |
| route groups | 路线分组数 |
| scheduled inspections | 当前条件下的巡检记录数 |
| open slots | 未设置巡检时间的记录数 |
| first date | 当前条件下最早巡检日期 |

### 11.3 Google Map

点击 `Load Google map` 后，系统会尝试加载 Google Maps 脚本，并对当前页最多 25 条地址进行地理编码展示。

如果未配置 `VITE_GOOGLE_MAPS_KEY`，页面会提示 Google Maps key 未配置。

### 11.4 Route Records 列表

表格展示字段包括：

- Customer name
- Sales
- MACID
- Phone
- Address
- Area
- Inspector
- Date
- Time
- Product
- Action
- Note

### 11.5 航迹 / 路线数据保存

在 Routes map 列表中，绿色编辑区域包含：

- `Inspector`
- `Date`
- `Time`
- `Product`
- `Note`

操作方式：

1. 修改绿色框内任意字段。
2. 字段下方显示 `Unsaved`，表示前端已修改但尚未写入数据库。
3. 点击该行 `Save` 按钮。
4. 保存中显示 `Saving...`。
5. 保存成功显示 `Saved`，数据已持久化到 MySQL。
6. 保存失败显示 `Save failed`，可检查网络或后端日志后重试。

注意：编辑绿色区域后必须点击 `Save`，否则刷新页面或切换分页后未保存内容可能丢失。

### 11.6 Routes map 行操作

| 按钮 | 功能 |
| --- | --- |
| Save | 保存当前行绿色编辑区域内容 |
| Detail | 查看当前记录详情 |
| Edit | 弹窗编辑完整记录 |
| Cancel | 将记录状态标记为 `Cancelled` |
| Delete | 删除当前记录 |

### 11.7 Routes map 导出与删除

| 按钮 | 说明 |
| --- | --- |
| Export all | 按当前路线筛选条件导出全部记录 |
| Export selected | 导出勾选记录 |
| Delete selected | 删除勾选记录；如果选择全部，则按当前路线查询条件删除全部匹配记录 |

## 12. 常见问题

### 12.1 导入失败：文件解析异常

可能原因：

- 文件不是 CSV / Excel 格式。
- CSV 内部引号、分隔符异常。
- 表头字段与模板差异过大。

处理方式：

1. 检查文件格式。
2. 用 Excel 打开后另存为标准 CSV。
3. 确认文件包含客户、MAC、电话、地址等核心字段。

### 12.2 Google Sheet 同步失败

可能原因：

- 未配置同步凭据。
- Apps Script Web App URL 或 secret 错误。
- 本机网络无法访问 `script.google.com`。
- 服务账号未被共享到目标 Sheet。

处理方式：

1. 点击 `Check Google Sheet` 查看具体提示。
2. 检查后端环境变量。
3. 检查代理或网络。
4. 查看后端日志中的 `GoogleSheetSyncService` 输出。

### 12.3 登录后菜单为空

可能原因：

- 用户角色没有菜单权限。
- `sys_menu` 初始化数据缺失。
- localStorage 中缓存异常。

处理方式：

1. 使用 `admin` 账号登录检查。
2. 确认 `sys_menu`、`sys_role_permission` 表数据。
3. 清理浏览器 localStorage 后重新登录。
