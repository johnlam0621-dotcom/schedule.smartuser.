# Schedule SmartUser 系统接口说明

## 1. 接口约定

后端基础地址：

```text
http://127.0.0.1:8088
```

前端开发环境通过 Vite 代理访问：

```text
/api -> http://127.0.0.1:8088
```

除登录和健康检查外，所有接口都需要登录 token。

请求头：

```http
Authorization: Bearer <token>
```

## 2. 统一响应结构

后端统一返回 `ApiResponse<T>`：

```json
{
  "success": true,
  "message": "ok",
  "data": {}
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 是否成功 |
| `message` | string | 提示信息 |
| `data` | object / array / null | 业务数据 |

失败示例：

```json
{
  "success": false,
  "message": "Unauthorized",
  "data": null
}
```

## 3. 状态码约定

| HTTP 状态码 | 说明 |
| --- | --- |
| `200` | 请求成功 |
| `400` | 参数错误、业务校验失败、重复数据 |
| `401` | 未登录或 token 无效 |
| `500` | 系统异常或数据库连接异常 |

## 4. 认证接口

基础路径：`/api/auth`

### 4.1 登录

```http
POST /api/auth/login
```

请求体：

```json
{
  "username": "admin",
  "password": "admin123"
}
```

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 登录 token |
| `user` | object | 当前用户 |
| `menus` | array | 菜单列表 |
| `permissions` | array | 权限编码列表 |

响应示例：

```json
{
  "success": true,
  "message": "ok",
  "data": {
    "token": "token-value",
    "user": {
      "id": 1,
      "username": "admin",
      "realName": "System Admin",
      "roleCode": "admin"
    },
    "menus": [],
    "permissions": ["inspection:import", "route:map"]
  }
}
```

### 4.2 当前用户

```http
GET /api/auth/me
```

说明：根据当前 token 返回用户、菜单和权限。该接口不返回新 token。

### 4.3 退出登录

```http
POST /api/auth/logout
```

说明：后端移除当前 token，会话失效。

## 5. 健康检查接口

基础路径：`/api/health`

### 5.1 服务状态

```http
GET /api/health/status
```

该接口不需要 token。

响应示例：

```json
{
  "success": true,
  "message": "ok",
  "data": {
    "service": "schedule-smartuser",
    "status": "UP"
  }

```

## 6. 系统管理接口

基础路径：`/api/system`

### 6.1 查询用户列表

```http
GET /api/system/users
```

响应 `data`：用户数组。

用户字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 用户 ID |
| `username` | string | 用户名 |
| `passwordHash` | string | 返回前会被清空 |
| `realName` | string | 真实姓名 |
| `roleCode` | string | 角色编码 |
| `status` | number | `1` 启用，`0` 禁用 |
| `createdAt` | string | 创建时间 |
| `updatedAt` | string | 更新时间 |

### 6.2 创建用户

```http
POST /api/system/users
```

请求体：

```json
{
  "username": "user1",
  "realName": "User One",
  "roleCode": "scheduler",
  "status": 1,
  "passwordHash": "123456"
}
```

说明：

- `id` 由后端置空。
- `passwordHash` 在请求中表示明文密码，后端会使用 BCrypt 加密保存。
- 不传密码时默认使用 `123456`。

### 6.3 更新用户

```http
PUT /api/system/users/{id}
```

请求体同创建用户。

说明：

- 路径 `id` 为用户 ID。
- 如请求体中包含非空 `passwordHash`，后端会重置密码。
- 如不传 `passwordHash`，只更新基础资料。

### 6.4 重置密码

```http
POST /api/system/users/{id}/reset-password
```

请求体：

```json
{
  "password": "new-password"
}
```

### 6.5 查询菜单列表

```http
GET /api/system/menus
```

响应 `data`：菜单数组。

菜单字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 菜单 ID |
| `parentId` | number | 父菜单 ID |
| `name` | string | 菜单名称 |
| `path` | string | 路由路径 |
| `component` | string | 前端组件 |
| `permissionCode` | string | 权限编码 |
| `sortOrder` | number | 排序 |
| `visible` | number | 是否可见 |

### 6.6 创建菜单

```http
POST /api/system/menus
```

请求体：

```json
{
  "parentId": 0,
  "name": "Routes map",
  "path": "/routes/map",
  "component": "RoutesMapView",
  "permissionCode": "route:map",
  "sortOrder": 60,
  "visible": 1
}
```

### 6.7 更新菜单

```http
PUT /api/system/menus/{id}
```

请求体同创建菜单。

### 6.8 查询权限列表

```http
GET /api/system/permissions
```

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 权限 ID |
| `code` | string | 权限编码 |
| `name` | string | 权限名称 |
| `description` | string | 权限描述 |

### 6.9 创建权限

```http
POST /api/system/permissions
```

请求体：

```json
{
  "code": "route:map",
  "name": "Routes map",
  "description": "View route map records"
}
```

### 6.10 更新权限

```http
PUT /api/system/permissions/{id}
```

请求体同创建权限。

## 7. 巡检导入接口

基础路径：`/api/inspections`

### 7.1 文件导入

```http
POST /api/inspections/import
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | CSV / XLS / XLSX 文件 |

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `batchId` | number | 导入批次 ID |
| `fileName` | string | 文件名 |
| `totalRows` | number | 扫描行数 |
| `successRows` | number | 成功行数 |
| `failedRows` | number | 失败行数 |
| `errors` | array | 逐行错误 |
| `googleSheetStatus` | string | Google Sheet 同步状态 |
| `googleSheetRows` | number | Google Sheet 同步行数 |
| `googleSheetMessage` | string | Google Sheet 同步说明 |

### 7.2 Google Sheet 状态检查

```http
GET /api/inspections/google-sheet/status
```

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `status` | string | `success`、`failed`、`skipped` |
| `rows` | number | 同步行数，状态检查通常为 `0` |
| `message` | string | 状态说明 |

### 7.3 导入记录分页查询

```http
GET /api/inspections/records
```

查询参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `startDate` | string | 否 | 无 | 开始日期 |
| `endDate` | string | 否 | 无 | 结束日期 |
| `inspector` | string | 否 | 无 | 检查员 |
| `sales` | string | 否 | 无 | 销售 |
| `keyword` | string | 否 | 无 | 客户、MAC、电话、地址、Sales 模糊查询 |
| `page` | number | 否 | `1` | 页码 |
| `size` | number | 否 | `10` | 每页条数，最大 `200` |

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `total` | number | 总记录数 |
| `page` | number | 当前页 |
| `size` | number | 每页条数 |
| `records` | array | 巡检记录列表 |

### 7.4 导入记录导出

```http
POST /api/inspections/records/export
Accept: text/csv
```

请求体：

```json
{
  "startDate": "2026-07-06",
  "endDate": "2026-07-06",
  "inspector": "Ronit",
  "sales": "",
  "keyword": "",
  "ids": [1, 2, 3]
}
```

说明：

- `ids` 有值时导出指定记录。
- `ids` 为空或不传时，按查询条件导出全部匹配记录。
- 响应为 CSV 二进制文件。

### 7.5 查询记录详情

```http
GET /api/inspections/records/{id}
```

响应 `data`：单条巡检记录。

### 7.6 更新记录

```http
PUT /api/inspections/records/{id}
```

请求体示例：

```json
{
  "rowNumber": 10,
  "dayName": "Tuesday 7-Jul",
  "status": "",
  "macId": "158131",
  "sales": "Sales A",
  "firstName": "Ashira",
  "lastName": "Halabi",
  "customerName": "Ashira Halabi",
  "phoneNumber": "410556466",
  "address": "41 Deakin Ave, Lalor VIC 3075, Australia",
  "suburb": "Lalor",
  "cityCouncil": "",
  "inspector": "Ronit",
  "inspectionDate": "2026-07-06",
  "inspectionTime": "1:00 PM",
  "projects": "MAC",
  "schedulerRemarks": "note",
  "quotationTeamReport": ""
}
```

说明：

- Routes map 行内 `Save` 按钮也调用该接口。
- 该接口会更新巡检业务字段，不更新导入批次 ID 和创建时间。

### 7.7 取消记录

```http
PUT /api/inspections/records/{id}/cancel
```

说明：将记录 `status` 更新为 `Cancelled`。

### 7.8 按查询条件删除记录

```http
DELETE /api/inspections/records/query
```

Inspection Import 请求体：

```json
{
  "startDate": "2026-07-06",
  "endDate": "2026-07-06",
  "inspector": "Ronit",
  "sales": "",
  "keyword": ""
}
```

Routes map 请求体：

```json
{
  "startDate": "2026-07-06",
  "endDate": "2026-07-06",
  "route": "Ronit"
}
```

说明：

- 传 `route` 时按路线筛选删除。
- 不传 `route` 时按导入列表筛选条件删除。
- 返回删除记录数。

### 7.9 删除单条记录

```http
DELETE /api/inspections/records/{id}
```

返回删除记录数。

### 7.10 批量删除记录

```http
DELETE /api/inspections/records/batch
```

请求体：

```json
{
  "ids": [1, 2, 3]
}
```

返回删除记录数。

## 8. 路线接口

基础路径：`/api/routes`

### 8.1 查询路线选项

```http
GET /api/routes/options
```

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `startDate` | string | 否 | 开始日期 |
| `endDate` | string | 否 | 结束日期 |

响应 `data`：

```json
{
  "routes": [
    {
      "routeName": "Ronit",
      "stopCount": 10,
      "startDate": "2026-07-06",
      "endDate": "2026-07-06"
    }
  ]
}
```

说明：

- `routeName` 当前按 `inspector` 聚合。
- 空检查员显示为 `Unassigned`。

### 8.2 查询路线地图和列表

```http
GET /api/routes/map
```

查询参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `startDate` | string | 否 | 无 | 开始日期 |
| `endDate` | string | 否 | 无 | 结束日期 |
| `route` | string | 否 | 无 | 路线名称 |
| `page` | number | 否 | `1` | 页码 |
| `size` | number | 否 | `10` | 每页条数 |

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `summary` | object | 统计汇总 |
| `total` | number | 总记录数 |
| `page` | number | 当前页 |
| `size` | number | 每页条数 |
| `records` | array | 巡检记录列表 |

`summary` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `routeGroups` | number | 路线组数 |
| `scheduledInspections` | number | 巡检记录数 |
| `openSlots` | number | 未设置时间的记录数 |
| `startDate` | string | 最早日期 |
| `endDate` | string | 最晚日期 |

### 8.3 导出路线记录

```http
POST /api/routes/map/export
Accept: text/csv
```

请求体：

```json
{
  "startDate": "2026-07-06",
  "endDate": "2026-07-06",
  "route": "Ronit",
  "ids": [1, 2, 3]
}
```

说明：

- `ids` 有值时导出选中记录。
- `ids` 为空或不传时，按路线查询条件导出全部匹配记录。
- 响应为 CSV 文件。

## 10. 错误处理说明

常见错误：

| 场景 | message 示例 | 说明 |
| --- | --- | --- |
| 未登录 | `Unauthorized` | token 缺失或失效 |
| 文件缺失 | `Upload file is required.` | 导入接口未上传文件 |
| 文件格式错误 | `Only csv, xls and xlsx files are supported.` | 只支持 CSV / Excel |
| 记录不存在 | `Inspection record does not exist.` | id 不存在 |
| 数据库连接异常 | `数据库连接超时，请稍后重试或检查 MySQL 连接。` | MySQL 不可用或连接池耗尽 |
| Google Sheet 超时 | `Google Sheet 连接超时...` | 网络或代理问题 |

## 11. 调用示例

### 11.1 登录并查询导入记录

```powershell
$body = @{ username = $env:SCHEDULE_USERNAME; password = $env:SCHEDULE_PASSWORD } | ConvertTo-Json -Compress
$login = Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8088/api/auth/login" -ContentType "application/json" -Body $body
$token = $login.data.token

Invoke-RestMethod `
  -Method Get `
  -Uri "http://127.0.0.1:8088/api/inspections/records?page=1&size=10" `
  -Headers @{ Authorization = "Bearer $token" }
```

### 11.2 更新 Routes map 绿色区域字段

```powershell
$payload = @{
  inspector = "Ronit"
  inspectionDate = "2026-07-06"
  inspectionTime = "1:00 PM"
  projects = "MAC"
  schedulerRemarks = "Add note update"
} | ConvertTo-Json -Compress

Invoke-RestMethod `
  -Method Put `
  -Uri "http://127.0.0.1:8088/api/inspections/records/1" `
  -Headers @{ Authorization = "Bearer $token" } `
  -ContentType "application/json" `
  -Body $payload
```

前端 Routes map 页面点击行内 `Save` 按钮时，即调用该更新接口持久化数据。
