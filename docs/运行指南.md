# Schedule SmartUser 运行指南

## 技术栈

- 前端：Vue 3 + Vite，端口 `5173`
- 后端：Spring Boot 2.7 + JDK 17，端口 `8088`
- 数据库：MySQL，数据库名 `schedule_smartuser`
- 会话缓存：Redis，默认地址 `127.0.0.1:6379`

## 初始化 MySQL

在 MySQL 中执行：

```sql
source D:/DOC/07_众方CRM/04_schedule/02_schedule-smartuser/database/schema.sql;
```

也可以使用项目辅助脚本：

```powershell
cd D:\DOC\07_众方CRM\04_schedule\02_schedule-smartuser
.\scripts\init-mysql-jdbc.ps1
```

项目不再保存弱默认密码。首次创建或恢复管理员时，在启动后端前临时设置：

```powershell
$env:SCHEDULE_BOOTSTRAP_ADMIN_PASSWORD="填写新的强密码"
```

成功启动并确认管理员可以登录后，立即删除该环境变量。数据库只保存 BCrypt 密码哈希。

## 启动后端

```powershell
cd D:\DOC\07_众方CRM\04_schedule\02_schedule-smartuser\backend
mvn spring-boot:run
```

可选环境变量：

```powershell
$env:MYSQL_USERNAME="root"
$env:MYSQL_PASSWORD="按实际数据库密码填写"
$env:REDIS_HOST="127.0.0.1"
$env:REDIS_PORT="6379"
```

如需把“检查导入”的成功记录同步到 Google Sheet，使用 Google 服务账号 JSON 文件，并把目标 Sheet 共享给该服务账号的 `client_email`。Google Sheets API 不能使用普通 Google 邮箱密码作为后端同步凭据：

```powershell
$env:GOOGLE_SHEET_SYNC_ENABLED="true"
$env:GOOGLE_SHEET_SERVICE_ACCOUNT_FILE="D:\path\to\service-account.json"
```

如果不想把 JSON 文件放在服务器上，也可以使用原始 JSON 或 Base64：

```powershell
$env:GOOGLE_SHEET_SERVICE_ACCOUNT_JSON='{"type":"service_account",...}'
$env:GOOGLE_SHEET_SERVICE_ACCOUNT_BASE64="base64后的service-account.json内容"
```

默认同步到以下表格配置：

```text
GOOGLE_SHEET_SPREADSHEET_ID=1rU3-k6VHuLnfIM2O6_H9L23ONH9lCG0idUv5BMa5p3M
GOOGLE_SHEET_GID=690390920
```

后端启动后可检查 Google Sheet 同步配置：

```text
GET /api/inspections/google-sheet/status
```

也可以使用 Google Apps Script Web App 同步。把 `scripts/google-sheet-sync-webapp.gs` 复制到目标表格的 Apps Script 中，修改 `SYNC_SECRET`，部署为 Web App 后配置：

```powershell
$env:GOOGLE_SHEET_WEB_APP_URL="Apps Script Web App /exec 地址"
$env:GOOGLE_SHEET_WEB_APP_SECRET="REPLACE_WITH_RANDOM_SECRET"
```

Google Sheet 仅作为只读数据源。导入、预约、取消和改期只写入应用数据库，不会修改 Google Sheet。

Web App 部署完成并拿到 `/exec` 地址后，也可以用脚本启动后端：

```powershell
cd D:\DOC\07_众方CRM\04_schedule\02_schedule-smartuser
.\scripts\start-backend-google-webapp.ps1 -GoogleSheetWebAppUrl "https://script.google.com/macros/s/REPLACE_WITH_DEPLOYMENT_ID/exec"
```

启动后检查同步配置：

```powershell
.\scripts\verify-google-sheet-sync.ps1
```

也可以通过脚本启动 MySQL + Redis 配置：

```powershell
cd D:\DOC\07_众方CRM\04_schedule\02_schedule-smartuser
.\scripts\start-backend-mysql.ps1
```
